# 00 · 迁移总览

## 一句话目标

把本地这份 Soybean Admin **从 pnpm monorepo 转为 Bun 工作流**，并借这次转换，**按后台管理系统的真实能力分层，用最新 Vue 生态亲手重写一遍**。

## 现状要说清楚

原项目**已经是** Vue 3 + TypeScript + Vite 8 + Pinia + Vue Router 5 + Naive UI + UnoCSS。

所以这次不是「从 Vue 2 升到 Vue 3」，也不是「从 JS 迁到 TS」。真正要做的是：

| 变化 | 说明 |
| --- | --- |
| 包管理器 / 运行时 | `pnpm` → `bun`（安装、脚本、workspace、lockfile） |
| 学习方式 | 不在原仓库上打补丁，而是根目录从零搭，`legacy/` 只当老师 |
| 版本策略 | 每一轮动手时安装当时的 **latest 稳定版** |
| 结构策略 | R00–R19 单包；R19 先锁定回归，R20 才用 Bun workspace 拆稳定内部包 |
| 复杂度策略 | 先实现「能登录、有布局、有权限、有主题」的内核，再补花活 |

归档后，原代码在 `legacy/`，对照路径一律写成 `legacy/src/...`。

## 要学会的能力（比「换成 bun」更重要）

1. **工具链**：Bun 如何替代 pnpm / node 跑脚本；Vite 8 如何开发与构建 Vue。
2. **Vue 3 应用骨架**：`createApp` → plugin → router → pinia → i18n → mount。
3. **后台内核**：登录态、路由守卫、静态/动态权限、多标签、布局、主题、请求封装。
4. **工程化**：TS 严格模式、路径别名、环境变量类型、lint/format、git hook。
5. **何时抽象**：什么时候把 axios 工厂、utils、color 等稳定边界抽成 workspace 包。
6. **如何证明完成**：自动化回归、生产构建/预览、功能对等清单三者必须同时通过。

## 原则

1. **可运行优先于完美抽象**。每一轮结束必须能 `bun run dev`（第 0 轮除外）。
2. **先理解数据流，再写 UI**。权限路由、请求拦截、Pinia 之间的边比组件皮肤重要。
3. **最新稳定版，不追 canary**。TypeScript 7 目前还不适合做 Vue 的默认编译器，见 [02-target-stack.md](./02-target-stack.md)。
4. **Naive UI + UnoCSS 保留**。这是这份模板的外观与交互身份，不在重写里换成 Element Plus。
5. **Elegant Router 后置**。前几轮用手写 `vue-router`，真正搞懂守卫后再考虑代码生成。

## 非目标

- 不 1:1 复刻全部主题预设、全部布局变体、全部登录模块。
- 不在第 1 轮引入 `@elegant-router/vue`、`@sa/scripts`、changelog 流水线。
- 不把 `legacy/` 提交进 git。
- 不在文档轮次里同时换 UI 库。
- 不把 Alova 作为默认请求库（原仓库有 `packages/alova`，但应用入口用的是 `@sa/axios`）。

## 成功长什么样

完成 R22 后，根目录应具备：

- 用 Bun 安装与启动
- TypeScript 严格模式通过
- 登录 / 首页 / 403 / 404 / 500
- 静态权限路由（动态路由作为加分项）
- 侧栏菜单 + 顶栏 + 内容区 + 多标签
- Axios 封装：token、成功码、过期刷新、登出码
- 亮暗色与主题色
- 中英 i18n
- 核心请求、权限、菜单、页签和登出清理的自动化回归
- 生产构建可预览

功能对照清单见 [mapping/features.md](./mapping/features.md)。

## 建议的时间盒

| 阶段 | 轮次 | 大约有效时间 |
| --- | --- | --- |
| 工具与骨架 | R00–R03 | 3.5–7 小时 |
| 页面底座 | R04–R06 | 4–7 小时 |
| 数据与权限 | R07–R10 | 7.5–12.5 小时 |
| 导航与个性化 | R11–R14 | 7–10.5 小时 |
| 页面交付 | R15–R17 | 5–9 小时 |
| 工程与交付 | R18–R22 | 9–16 小时 |

合计约 **36–62.5 小时**。如果每天能保持 4–6 小时有效学习，通常需要 8–12 天；初次深挖权限或 KeepAlive 时可能更长。

这是学习节奏，不是赶工排期。卡住就停在当前轮，对照 `legacy/` 把那一条数据流画出来再写。
